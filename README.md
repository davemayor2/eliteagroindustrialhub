# Elite Agro Industrial Hub Ltd

Official MVP website for **Elite Agro Industrial Hub Limited (RC. 9831149)** — featuring **Elite Palm Field**, a managed oil palm farm estate in Ifite-Ogwari, Anambra State, Nigeria.

## Tech Stack
- Pure static HTML5 (`index.html`), CSS3 (`styles.css`), and vanilla JavaScript (`script.js`)
- Zero build step — ready for immediate hosting on GitHub Pages, Netlify, Vercel, or standard web hosting.
